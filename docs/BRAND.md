# Verda Padel identity

Authoritative supplied colors: Verda green `#03764A`; white `#FFFFFF`.
The original PNG is preserved at `app/static/images/verda-logo.png`. Do not distort, redraw or recolor its artwork. Fit the complete image within a white container.

White against Verda green has a calculated contrast ratio of 5.68:1. The primary button and navigation pair use these two colors. Green-tinted surfaces and borders support the interface; status messages also use text labels. English uses LTR; Arabic and Kurdish use RTL.

Design direction: an editorial sports identity with spacious white layouts, expressive headings, clear green actions and abstract court geometry. Abstract illustrations do not depict the actual venue. Operational interfaces use a compact sidebar, structured lists and large POS controls. Shared CSS tokens control spacing, radius, typography and motion.

Representative layouts are the homepage, booking planner, operational dashboard and court/table cashier view. All subsequent screens use the same components.
